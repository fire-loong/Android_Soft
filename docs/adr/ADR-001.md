# ADR-001：技术版本与 Monorepo（锁定基线）

状态：已采纳（2026-11-21）
范围：ActionLoop 全部工程
依据：《日常生活行动系统完整开发指导书》第 10 章、附录 E

## 背景
为保证三端与后端契约一致、可复现构建，所有精确版本在初始化时锁定，不允许各端自行升级。任何版本变更须新开 ADR 并跑对应验证门。

## 决定：精确版本锁定

### 语言与运行时
- 后端：Java 21（Eclipse Temurin 21.0.12），Spring Boot 3.3.5，Maven Wrapper 3.9.9。
- Android：Kotlin 2.1.10，Jetpack Compose BOM 2025.04.01，AGP 8.7.3，Gradle 8.10.2；minSdk 26，compileSdk/targetSdk 35。
- Web：Node.js 20+（实测 22.23.4；指导书建议 24 LTS，22 满足 Vite/React 19 要求，CI 对齐 22），pnpm 10.15.0（packageManager 锁定）；package.json 以 caret 范围声明，**实际锁定版本以 pnpm-lock.yaml 为准（CI `--frozen-lockfile` 强制复现）**：TypeScript 5.9.3、React/ReactDOM 19.3.1、Vite 6.4.6、Ant Design 5.29.3、TanStack Query 5.108.2、React Router 7.18.6、axios 1.21.1、vitest 2.1.9。
- Windows：Tauri 2.3.0，Rust stable（MSRV 1.77），复用 Web 构建产物。

### 数据与基础设施
- 数据库：PostgreSQL 16 + pgvector（指导书锁定）。
  - **本地偏差**：开发机已运行本机 PostgreSQL 17 服务；本地独立集群使用 PG 17 二进制（端口 5433）以获得无管理员凭据的受控环境。PG 17 对本项目 SQL/pg_trgm/uuid-ossp 向下兼容；向量扩展 pgvector 待安装（阶段 6 启用，已在迁移中预留）。生产与 docker compose 路径仍使用 PG 16 + pgvector 镜像。
- 缓存：Redis 7。
- 对象存储：S3 兼容（开发 MinIO，生产私有桶）。
- 实时：Spring WebSocket + WebRTC + Coturn。

### 契约与规范
- OpenAPI 3.1 为三端 REST 唯一契约源，CI 生成 TS/Kotlin 客户端。
- Flyway 迁移命名 `V<yyyyMMddHHmm>__<desc>.sql`，禁止生产 `ddl-auto=update`。
- 主键 UUIDv7；时间 UTC `timestamptz`；状态/日期格式三端统一。

## 后果
- 升级任一锁定版本须：新开 ADR → 跑验证门（G-SYS/G-OCR/G-LLM/G-SYNC/G-SEC）→ 更新本文件与依赖锁 → CI 通过。
- 本地 PG17 偏差仅限开发环境；CI、staging、生产必须使用 PG16 + pgvector，避免特性差异。

## 本地开发环境决策（开发机特例，不影响生产/CI）
- **对象存储（MinIO）**：MinIO 社区版归档下载官方端点返回 410、GitHub Release 无 asset，本地暂未部署。对象存储接入推迟到阶段 2 之前；阶段 2 的文件私有存储先以本地磁盘 provider 落地，保留 S3 兼容 Provider 接口，生产仍走私有 S3/MinIO 桶。须在阶段 2 前新开 ADR 选型 S3Proxy/SeaweedFS 等可下载替代。
- **Redis 健康检查**：Windows 版 Redis（tporadowski 5.0.14.1）`INFO` 输出中 `executable` 字段路径含反斜杠，Spring Boot 默认 RedisHealthIndicator 用 `Properties.load` 解析时将 `\u` 当作 Unicode 转义导致健康 DOWN。已改为自定义 PING→PONG 指示器并禁用默认 redis health（`management.health.redis.enabled=false`）。CI/生产使用官方 Redis 7 镜像，不受此影响。
- **Android 构建路径**：工作区根路径含中文（非 ASCII），AGP 在 Windows 上默认拒绝构建（`b.android.com/95744`）。本地通过 ASCII 目录联接 `C:\ActionLoopBuild → <repo>` 执行 Gradle，并在 `apps/android/gradle.properties` 设置 `android.overridePathCheck=true`；`gradle-wrapper.properties` 的 `distributionUrl` 指向腾讯镜像以规避 `services.gradle.org` 被墙。仓库物理位置不变，生产/CI（Linux ASCII 路径）无需此变通。
- **后端启动方式**：中文路径下 `spring-boot:run` fork JVM 会 `ClassNotFoundException`，本地统一以 `java -jar api/target/actionloop-api.jar` 启动（repackage 绑定在父 POM 的 pluginManagement 中）。
